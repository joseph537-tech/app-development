## 🛠️ Getting Started Locally

To run either of these applications on your local machine, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate into the target project folder:**
   ```bash
   cd student_persona_card
   ```
3. **Fetch dependencies:**
   ```bash
   flutter pub get
   ```
4. **Run the application:**
   ```bash
   flutter run
   ```
